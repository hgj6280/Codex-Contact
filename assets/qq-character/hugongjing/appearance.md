# 狐宫静形象定稿

这两张图都是狐宫静同一个角色的正面设定，不是两个人。以 reference-default.png（不戴帽子）作为默认身份参考；reference-summer.png 是增加草帽和墨镜的夏日配饰版。用户提供的原稿保存在 originals/，生图使用等比例缩小的 reference 文件。

## 必须保持的辨识特征
- 人形狐娘；可以画成圆润、软萌的 Q 版，但不能在未被要求时变成普通四足小狐狸、猫娘或其他角色。
- 浅金黄色长发，发梢有浅桃橙色过渡；额前有分束刘海，头顶一缕弯曲呆毛。头发长度、轮廓和配色以基础参考图为准。
- 红色至红棕色的大眼睛，有明亮高光；不可随意改成蓝眼或绿眼。
- 一对直立的大狐狸耳朵，外侧金橙色，内侧浅桃色并带白色绒毛；不是猫耳。
- 一条蓬松的大金色狐狸尾巴，奶油浅金色毛区和桃橙色外缘；不要凭空增加尾巴数量。
- 头部两侧为深蓝、亮蓝相间的蝴蝶结和垂落飘带，带浅色边线。
- 画面右侧（角色左侧）的刘海旁有白色小花与浅蓝爱心发夹。Q 版可以简化线条，但应保留两种图案。
- 基础服饰为白色、浅蓝色和深蓝色的水手风夏装：深蓝水手领带白色线条、白色荷叶边、胸前深蓝蝴蝶结和一枚金色铃铛。胸像表情包也尽量保留胸前蝴蝶结与铃铛。
- 画全身时参考浅蓝白荷叶边短裙、深蓝裙边、蓝色花饰飘带及蓝色凉鞋；不要无故换成其他制服。

## 可变部分
- 表情、动作、文字、构图和 Q 版比例可以随需求改变；可爱、害羞、委屈、得意、炸毛等情绪不改变角色身份。
- 草帽、花饰、额头上的圆框墨镜属于夏日可选配饰。普通表情包默认不戴帽子和墨镜，明确要求夏日/沙滩/草帽主题时才使用配饰版。
- 用户明确要求换装或某种画风时可以改变服装或画风，继续保留发色、红眼、狐耳尾巴、发饰等核心特征。
- 设定图的留白、底色和透明显示产生的黑块不属于角色，不要复制到表情包中。

## 生图使用规则
- 生成狐宫静时必须实际引用基础参考图，不能只凭名字或“金发狐娘”文字重新设计。
- 群友要求“生成/画一张表情包”，且没有指定其他角色时，默认用狐宫静；“你/你的形象/你自己”在角色生图语境也指狐宫静。
- 群友明确指定其他人物、动物或物品时按该指定生成，不把其强制改成狐宫静。用户附图如仅用于模仿动作、表情、构图或文字，应保持狐宫静身份。
- 输出前核对红眼、金发、狐狸耳尾、蓝色蝴蝶结、花与爱心发夹、金铃铛；遮挡或裁切可自然省略，不得用错误特征替代。
