# 狐宫静 QQ 桌面版

独立 macOS 客户端，复用现有 CodexRemoteContact + NapCat 服务，不替换官方 QQ。
使用 AppKit 和系统 WebKit，不随 App 打包 Electron、Node、QQ 登录容器或模型。

## 已实现

- 全部 QQ 好友、已加入群聊，最近 300 条消息，搜索及新消息提示。
- 手动文字、图片、表情包、引用回复、真正的 @ 群成员；先显示发送中，收到消息编号后才显示已发送。
- 群成员搜索、群名片、群名称、禁言/解禁、全员禁言、移出成员、任免管理员；每次操作按 QQ 当前权限校验并要求确认。
- 好友与入群申请收件箱，同意/拒绝；主动添加好友暂需手机 QQ，当前 NapCat 没有对应接口。
- AI 帮写和生图的独立预览任务；点击“放入输入框”后仍需手动发送。
- 现有 OC 参考、引用图片、生图验收和下载归档复用后台流程。
- AI 自动回复开关、实际模型设置和用量；公开显示名与实际模型区分。
- 夜间模式；App 内扫码登录、后台恢复、管理面板及下载目录入口。
- 小程序/分享卡片展示安全的标题、描述及网页入口。

已移除小程序栏目与打开官方 QQ 的专用入口；保留聊天消息里的分享卡片。
同步完整联系人，但只显示服务已收集的聊天记录，不导入官方 QQ 的全部历史。
QQ 图片由本机安全缓存（保留 GIF 动画），失效时尝试通过消息编号/图片文件重新取得链接；无法恢复的旧图提供重试，不伪装成已加载。

## 构建与启动

在项目目录执行 `zsh modules/qq-desktop/build.command`。
默认安装到 `~/Applications/狐宫静 QQ.app`。
构建需要 macOS Command Line Tools，不需要 npm 安装新的 UI 框架。

后台未运行时，App 显示“启动 / 恢复后台”。恢复仅启动已登记的
`local.codexremotecontact.chat-hub` 与 `local.codexremotecontact.qq-napcat`，
不会强制重启已经工作的服务、重新登录 QQ 或改变 AI 开关。
NapCat 容器及 Docker 仍需正常运行；会话过期须在扫码登录窗口人工确认。

关闭 App 或窗口不关闭后台 AI。需要停止群友自动回复，请关闭界面的 AI 自动回复开关。
网页同样可访问 `http://127.0.0.1:3789/desktop.html`，但系统级入口仅在 App 内有效。

## 安全及轻量化

聊天与模型写接口只接受本机同源访问；桌面管理接口使用独立本机凭证，模型没有管理接口。
`bridge.json` 的 `accessMode: "all-contacts"` 按真实好友与群成员资格自动授权 AI，每分钟同步；陌生私聊不放行。保留 @／狐宫静触发、禁用开关、屏蔽列表与机器人回环保护。
群内指令：`@狐宫静 /禁言 @成员 10分钟`、`@狐宫静 /解除禁言 @成员`。发指令者与机器人必须都具备足够的实际群权限；`/ban` 仍是机器人忽略名单，不是 QQ 禁言。
图片限制 5 MiB，文件头验证，引用不得跨会话；发送请求编号防止并发/重试重复投递。
AI 草稿队列最多同时 2 个任务、每个会话 1 个，无 QQ 发送接口。
前台约 2 秒轮询，后台/隐藏约 15 秒仅检查连接，不拉取和重绘聊天、解码新图片；回到前台立即补齐。后台服务仍正常收集消息和回复。ETag 省去未变更的消息传输。
初始最多渲染 80 条，图片懒加载，表情列表每页 42 个。
前端仅缓存最近 8 个会话，切换大量群聊不会无限累积消息；淘汰的缓存可重新读取，不删除后台记录。皮肤只用 CSS，没有附加字体、角色大图或 UI 框架。
客户端体积不包含共享后台、已有聊天/表情素材与生图文件；不能视为可单独迁移的完整安装包。

自动测试：`node --test src/*.test.mjs modules/qq-napcat/conversation-queue.test.mjs`。

## 本地运行副本

LaunchAgents 使用 `~/Library/Application Support/CodexRemoteContact/service-code`，不直接读取可能被 iCloud 回收的 Documents 源代码。数据、QQ 登录和 Docker 挂载沿用原有本地位置。
修改源码后先执行 `node scripts/deploy-local-services.mjs` 发布完整副本，再在没有生成/发送任务时重启消息后台。脚本原子切换版本并保留旧版本，不删除源码或聊天记录。
侧栏采用并排布局；小窗口暂时收起会话列表，点“聊天”或“收起”恢复。人设和模型在“设置”，帮写和生图在“AI 创作”。
