# QQ 角色库

软件中打开 **设置 → 角色库 · 录入人物与参考图**。默认显示统一角色库中的全部角色；新增角色时先选择所属群聊或私聊。
可以新增、更新、删除角色卡，填写名字、别名、外观设定，并附 1–3 张参考图（每张最多 5 MB）。
不选新图片时保留旧参考图。群内共用角色限本群；私聊角色仅限当前私聊，重启保留。
角色卡独立于狐宫静的人设和逐发送者个人记忆，不将昵称或 OC 自动当作现实人物。

聊天中可附图片或引用原图：

- `/角色 录入 星铃：浅蓝短发、橙眼、黑色侦探帽、蓝格裙`
- `录入这个角色，这个角色名字叫星铃，以后也可以给他生图`
- `/角色 列表`
- `/角色 查看 星铃`
- `/角色 删除 星铃`（仅创建者、已配置控制者，或本机管理面板）

只有成功持久化后才确认录入；录入时提到“以后生图”不会现在生成。
以后说“给星铃生成这个表情包”或“把这个表情包的角色替换成星铃”：
角色卡和身份图决定外观，本次附图或引用图决定动作、表情、文字和构图。
身份图实际进入 GPT CLI 的图像输入与 image_gen 引用要求，以及 Gemini 的多模态参考图。
文字角色卡同样传给两条绘图路线。多角色用途不明时先澄清，不盲目混合。

本地存储：运行目录 `data/qq-roles/roles.sqlite` 和按内容哈希去重的图片。
SQLite WAL，256 KB 页缓存；仅本地按会话检索，无常驻模型、无额外聊天分类调用。
修改/删除使用 revision 防止并发覆盖；删除卡片保留原聊天及素材文件。

## 统一存储与迁移

所有已录入角色、别名、外观、归属范围和参考图集中在本机：
`~/Library/Application Support/CodexRemoteContact/data/qq-roles/`

- `roles.sqlite`：全部群聊与私聊的角色卡及使用范围。
- `images/`：按 SHA-256 去重的参考图。
- `builtin/hugongjing/`：狐宫静的基础图、夏日图和外观描述。绘图与桌宠等原有入口均读取这份本地资料；原来源/旧缓存保留作恢复副本。

统一存储及管理不会自动扩大私聊/群聊的使用权限。内置狐宫静卡在角色库只读展示，不覆盖普通角色或机器人聊天人设。

点 **导出完整角色库到下载**，得到一个 `.qqroles.gz` 文件，包含以上角色卡、用途范围和全部身份图，不包含聊天记录、账号密钥或模型授权。
在另一台机器安装 QQ 群友后，在相同设置页选择文件并点 **合并导入**。
导入校验每张图的 SHA-256，恢复相对路径；同一份重复导入不重复新增。
同编号/同名/别名冲突或内置图不同会报告并保留本机版本，不自动覆盖。
迁移包单次最大 32 MB，解包素材最大 80 MB；超限明确提示，完整目录仍可在服务停止后整体复制（包含 SQLite WAL 文件），不可只拷贝数据库主文件。
