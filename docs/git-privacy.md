# 本地提交与历史核查

本项目只跟踪源码、示例、测试与角色外观文字说明。聊天数据、密钥、运行时目录和链接留在安装目录。新安装的运行参数和会话权限由部署者在本机配置，仓库中的演示账号仅供测试。

在新的工作副本中先设置本仓库的 GitHub noreply 邮箱，然后启用随仓库分发的检查。

```sh
git config --local user.email '替换为个人 GitHub noreply 邮箱'
git config --local core.hooksPath .githooks
python3 scripts/test-private-data.py
python3 scripts/check-private-data.py --history
```

提交前读取 Git 索引的快照。检查账号格式、凭据模式、作者和提交者身份、文件路径及二进制内容。提交说明也经过检查。合成测试号保留 10001 到 10064、20001 到 20064。运行时目录及符号链接即使被强行暂存也会被拦截。

源码中需要保留的超时、容量、测试时间戳、颜色和哈希也可能长得像账号。审阅清单按文件保存含这些数字的完整行的 SHA-256 摘要；这些行一旦变动，需要重新审阅。角色图片保存在仓库外。不要为真实身份或密钥添加例外。历史检查遍历所有本地引用可达的提交，以每个提交自己的文件树和审阅清单为准。钩子是本机防误提交措施，规则识别有范围。
